# This folder contains the n8n workflows that are automatically imported
# when you run the project for the first time with `docker-compose up`.
#
# To add a workflow:
# 1. In n8n, go to the workflow > “⋯” menu > Download.
# 2. Place the exported .json file directly in this folder.
# 3. The next time you start the containers from scratch, it will import automatically.
